# Demonstração

Título: **E se o próximo Front-End rodar dentro da IA?**

## Preparação
Criar projeto fictício TypeScript com Vitest e PR com três mudanças: visual simples, comportamento que exige revisão e falha de idempotência em pagamento. Manter cenário reproduzível e evidências esperadas documentadas. Usar dados sintéticos; integrações reais quando habilitadas.

## Roteiro de 12 minutos
| Tempo | Ação |
| --- | --- |
| 0–2 min | Apresentar o desafio de revisar código com contexto |
| 2–4 min | Pedir análise de PR e explorar resumo/arquivos |
| 4–6 min | Abrir diff, explicar alteração e sugerir teste |
| 6–7 min | Perguntar onde a interface está rodando e revelar MCP Apps |
| 7–10 min | Explicar host, servidor, recurso UI e chamadas bidirecionais |
| 10–12 min | Mostrar limites, aplicações e próximos passos |

## Checklist
- [ ] Conexão com host validada na máquina da apresentação.
- [ ] PR e commit de referência disponíveis.
- [ ] Credenciais configuradas sem aparecer na tela.
- [ ] Ensaio com latência real e falha controlada.
- [ ] Gravação de backup disponível.
- [ ] Modo fixture claramente identificado se utilizado.
- [ ] Esclarecer que testes sugeridos não foram executados e revisão humana continua necessária.
